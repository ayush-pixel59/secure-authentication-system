# Secure Authentication System

A secure login system built with Flask, demonstrating user registration, password hashing, and JWT-based authentication.

## Technologies Used
* Python & Flask
* Flask-JWT-Extended
* Flask-Bcrypt
* SQLAlchemy & PostgreSQL

## How to Run
1. Clone the repository.
2. Create a virtual environment: `python -m venv venv`
3. Activate the environment.
4. Install dependencies: `pip install -r requirements.txt`
5. Create a `.env` file with your `SECRET_KEY`, `JWT_SECRET_KEY`, and `DATABASE_URL`.
6. Run the app: `python app.py`
